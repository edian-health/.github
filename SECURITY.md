# Security policy

## Reporting a security problem

If you think you've found a security problem in any Edian Health code or service, please email **saul@edian.ai**. Please don't open a public issue or pull request about it.

Include what you found, where you found it, and the steps to reproduce it if you can. We'll acknowledge your report and keep you updated until it's resolved.

## Scope

This policy covers all repositories in the Edian Health GitHub organisation and the services they run.
